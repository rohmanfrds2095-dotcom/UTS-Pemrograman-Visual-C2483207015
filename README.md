Deskripsi Aplikasi
Aplikasi Kasir Kantin Kampus berbasis Java Swing untuk menghitung total harga dan uang kembalian satu transaksi tanpa database.

Daftar Fitur
1. Input nama barang, harga satuan, jumlah pembelian, uang pembayaran
2. Hitung total harga
3. Hitung uang kembalian
4. Validasi input (kolom kosong, angka salah, pembayaran kurang)
5. Reset Form

Komponen Java Swing Yang Digunakan
JFrame, JPanel, JLabel, JTextField, JButton, JOptionPane

Cara Menjalankan Aplikasi
1. Buka project di Apache NetBeans
2. Run Class KasirKantinKampus
3. Isi data transaksi
4. Tekan Hitung → Bayar → Reset
